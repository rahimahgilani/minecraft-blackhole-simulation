# Minecraft-Style Black Hole Earth Simulation

> A visually stunning, interactive, and scientifically grounded simulation that lets you explore the mysteries of a black‑hole‑infested Earth.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/rahimahgilani/minecraft-blackhole-simulation.git
cd minecraft-blackhole-simulation

# Open the live demo
open https://rahimahgilani.github.io/minecraft-blackhole-simulation/
```

## 🎮 What’s Inside?

| Feature | Description |
|---------|-------------|
| **Real‑time rendering** | Uses WebGL and Three.js to deliver smooth 60 fps visuals.
| **Physics‑based gravity** | Implements a simplified Schwarzschild metric for realistic tidal forces.
| **Educational overlays** | Hover over objects to see scientific facts and equations.
| **Social sharing** | One‑click export to Twitter, Facebook, or Instagram.
| **Modular architecture** | Easy to extend with new celestial bodies or interaction modes.

## 📚 How It Works

The simulation is built on a small set of core concepts:

1. **Coordinate system** – A 3‑D Cartesian grid centered on the black hole.
2. **Gravitational potential** – Calculated using the Schwarzschild solution.
3. **Particle system** – Earth’s surface and atmosphere are rendered as a mesh of particles.
4. **User interaction** – Mouse/trackpad controls for orbit, zoom, and rotation.

For a deeper dive, check out the [docs](docs/).
